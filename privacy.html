2. 처리하는 정보와 이용 목적

기기에 저장하는 정보

웹사이트의 즐겨찾기는 브라우저 저장소에, 앱의 즐겨찾기·여행별 폴더·메모·설정은 기기에 저장하여 사용자가 선택한 내용을 다시 보여주는 데 이용합니다. 비로그인 저장은 기기에만 남습니다. Google 로그인 후에는 계정의 찜·여행 폴더·메모를 서버에 저장하고 같은 계정의 앱·웹에서 동기화합니다. 비로그인 저장은 로그인 계정에 자동 합쳐지지 않습니다. 저장된 장소를 조회할 때 해당 장소의 식별자가 서버로 전송될 수 있습니다.

선택적 Google 로그인과 광고 제거

Google 로그인은 선택 사항입니다. 등록된 이메일, Google 계정 고유 식별자, 혜택 상태, 등록 시각 및 등록자 식별자를 Cloudflare D1에 저장하여 광고 제거 대상 확인과 기기 변경 후 복구에 이용합니다. Google이 발급한 인증 토큰으로 본인을 확인하며 비밀번호는 받지 않습니다. Google 인증 토큰을 검증한 뒤 별도의 서비스 세션을 발급합니다. 앱은 Android Keystore로 암호화하여 저장하고 웹은 해당 브라우저의 사이트 저장소에 보관합니다. 서버에는 세션 토큰의 해시를 저장하며 마지막 인증 사용 후 30일이 지나면 만료됩니다. 그 전에 사용하면 30일로 연장됩니다. 계정의 저장 장소·여행 폴더·메모는 기기 간 동기화에 이용합니다.

원화 참고 금액

Frankfurter 환율 API에 접속해 최근 제공된 환율로 현지 가격을 원화로 환산합니다. 해당 제공처는 통신에 필요한 IP 정보를 처리할 수 있지만 검색어·Google 계정 정보는 전송하지 않습니다. 환율 제공처 안내

검색과 콘텐츠 제공

장소 검색 시 검색어, 국가·권역·도시·음식 분류, 페이지 번호, 조회할 장소 식별자 등이 검색 서버로 전달됩니다. 통신 과정에서 IP 주소와 접속에 필요한 요청 정보가 처리됩니다. 이는 검색 결과 제공, 서비스 안정성 유지 및 과도한 요청 제한에 이용됩니다. 현재 검색 기능은 별도의 회원별 검색 이력 데이터베이스를 만들지 않습니다.

웹사이트 방문자 집계와 요청 제한

같은 IP의 중복 방문을 하루 한 번으로 집계하기 위해 IP를 날짜별로 변환한 해시값을 저장합니다. 원본 IP는 방문자 집계 데이터에 저장하지 않습니다. 검색 및 제보의 과도한 요청을 막기 위해서도 IP에서 생성한 해시값과 요청 횟수를 일시 처리합니다. 해시값을 사용하더라도 개인정보와 무관한 정보라고 간주하지 않습니다.

앱 및 계정 메뉴의 오류·요청

Google 로그인한 사용자가 제보하면 이메일, 계정 식별자, 제목·내용, 접수 시각, 처리 상태와 운영자 답변을 Cloudflare D1에 저장합니다. 작성자 본인과 운영자만 조회할 수 있습니다. 하루 10회로 제한하며 목록 화면은 30초마다 갱신합니다. 계정 삭제 시 해당 계정의 제보도 삭제합니다. 기존 홈페이지 별도 제보 양식은 아래 정책을 따릅니다.

오류 제보·건의·이메일 문의

사용자가 직접 제출한 유형, 제목, 내용, 선택 입력한 이메일 주소, 선택 중인 국가·권역·도시, 접수번호 및 접수 시각을 문제 확인과 답변에 이용합니다. 회신 이메일 입력은 선택 사항이며, 입력하지 않아도 제보할 수 있습니다. 제출 내용은 일반 이용자에게 공개하지 않고 운영자용 비공개 관리 공간에서 처리합니다. 비밀번호, 신분증 번호 등 민감한 정보는 보내지 마세요.

외부 콘텐츠와 홍보 링크

4. 보관 기간과 삭제

  • 기기 저장 정보: 사용자가 삭제할 때까지 보관됩니다. 즐겨찾기·폴더·메모는 앱 내 삭제 기능을 이용하거나 Android의 앱 저장공간에서 데이터를 삭제할 수 있습니다. 웹 즐겨찾기는 브라우저의 해당 사이트 데이터를 삭제하여 지울 수 있습니다. 앱 삭제·기기 변경 후 복구는 보장되지 않습니다.
  • 방문자 집계: 날짜별 해시 집계 키는 마지막 집계 갱신 후 48시간이 지나면 자동 만료됩니다.
  • 요청 제한: 검색 요청 횟수 키는 약 2분, 검색 제한 기록은 1시간, 제보 요청 횟수 키는 15분 후 만료됩니다. 제보 중복 방지를 위한 접수번호는 30일 후 만료됩니다.
  • 제보·문의: 문제 처리와 답변을 위한 비공개 기록으로 보관됩니다. 현재 제보 본문에는 일괄 자동 만료가 적용되지 않으며 운영자가 관리합니다. 삭제를 원하면 아래 연락처로 요청할 수 있습니다. 처리 목적이 끝나 보관할 필요가 없어진 개인정보는 운영자가 삭제합니다. 법령상 보관 의무가 있는 경우에는 해당 기간 동안 분리하여 보관할 수 있습니다.
  • 계정·광고 제거 혜택: 혜택 제공 기간 동안 보관하며 본인이 삭제하면 운영 DB의 이메일·Google 식별자·혜택·세션·계정 찜과 여행 폴더·제보 및 해당 관리 기록을 제거합니다. 타인에게 부여한 혜택의 등록자 정보는 비식별 표기로 바꿉니다. 복구용 백업은 Cloudflare의 복구 보관 정책에 따라 소멸합니다.
  • 인프라 접속 기록: 호스팅·네트워크 제공자가 보안과 운영을 위해 처리하는 기록은 해당 제공자의 보관 정책과 서비스 설정에 따릅니다.

전자적 정보는 해당 저장소에서 삭제하며, 기기 데이터 삭제 후에는 복원이 어려울 수 있습니다.
