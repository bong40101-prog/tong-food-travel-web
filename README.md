# 통도락여행

유튜브에서 방문이 확인된 식당과 여행지를 찾는 정적 웹사이트입니다. 첫 화면은 음식 종류별 대표 식당을 표시합니다. 상단 통합 검색과 권역·도시·음식 필터로 전체 장소를 탐색할 수 있습니다. 즐겨찾기는 회원가입 없이 현재 브라우저에 저장됩니다.

## 실행과 배포

빌드나 API 키 없이 GitHub Pages에서 동작합니다. 배포 소스는 `main` 브랜치의 루트입니다.

```sh
python3 -m http.server 8000
node --test scripts/check.test.mjs
```

## 장소 추가

국가·권역·분류 설정은 `data/countries.json`에 둡니다. 장소 원본은 운영 서버의 비공개 저장소에서 관리합니다. 브라우저는 검색이나 필터에 해당하는 장소를 한 페이지씩 조회합니다. 새 장소를 공개 정적 JSON으로 추가하지 않습니다.

원본 영상이나 설명란에서 실제 방문한 지점이 확인되고, 대표 메뉴 가격 또는 입장료 출처를 확인한 장소를 등록합니다. 무료 여행지는 무료임을 확인한 출처를 기록합니다. 방문한 곳에 대한 명시적인 추천이 확인된 경우 영상 출처에 `recommended`를 붙입니다. 영상 설명란에서 시점을 확인할 수 있으면 `seconds`를 기록합니다. 가격은 현지 통화로 표시하고 출처와 확인일을 함께 공개합니다.

영상과 지도는 원본 서비스에 연결합니다. 실제 장소와 재사용 권한을 확인한 사진에는 촬영자, 라이선스, 편집 내역을 함께 기록합니다.
